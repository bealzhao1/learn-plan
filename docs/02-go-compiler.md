# Go 编译原理

## 2.1 编译流程

```
源代码 (.go)
    │
    ▼
┌─────────────┐
│  词法分析    │  scanner → token 流
└─────────────┘
    │
    ▼
┌─────────────┐
│  语法分析    │  parser → AST (抽象语法树)
└─────────────┘
    │
    ▼
┌─────────────┐
│  类型检查    │  type checker → 类型标注的 AST
└─────────────┘
    │
    ▼
┌─────────────┐
│  中间代码    │  AST → SSA (Static Single Assignment)
└─────────────┘
    │
    ▼
┌─────────────┐
│  代码优化    │  死代码消除、内联、逃逸分析等
└─────────────┘
    │
    ▼
┌─────────────┐
│  机器码生成  │  SSA → 目标平台机器码
└─────────────┘
    │
    ▼
┌─────────────┐
│  链接        │  合并目标文件 → 可执行文件
└─────────────┘
```

## 2.2 关键阶段详解

**词法分析 (Lexer/Scanner)**
- 将源代码字符流分割为 token（关键字、标识符、运算符、字面量）
- Go 使用 `go/scanner` 包实现
- 自动插入分号（ASI 规则）

**语法分析 (Parser)**
- 将 token 流构造为 AST
- Go 使用自顶向下递归下降解析器
- `go/parser` 包可直接使用

**SSA（静态单赋值）**
- 每个变量只被赋值一次
- 便于优化：常量传播、死代码消除、函数内联
- 可通过 `GOSSAFUNC=funcName go build` 查看 SSA 生成过程

## 2.3 链接器

- Go 使用自己的链接器（非 GNU ld）
- 支持两种链接模式：
  - **内部链接**：纯 Go 代码，链接更快
  - **外部链接**：涉及 cgo 时调用系统链接器
